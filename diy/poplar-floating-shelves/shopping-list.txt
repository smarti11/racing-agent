POPLAR FLOATING SHELVES — SHOPPING LIST
=======================================

WOOD
----
[ ] Poplar — enough for 2 shelves @ 20 × 6 × 1.5 in (+25% waste)
    Prefer: 3/4 in × 6 in × 6 ft (laminate) OR 8/4 × 6 in × 3 ft

HARDWARE
--------
[ ] Floating shelf brackets × 2 sets, each rated ≥ 30–50 lb
    Prefer plate-style or multi-rod kits that can span studs while shelf stays centered
[ ] Structural screws for brackets (#8 or #10 into studs — use kit-specified length)
[ ] Wood glue (Titebond II or III) — if laminating
[ ] Optional: shelf set screws / locking hardware if included with kit

FINISH
------
[ ] Sandpaper: 120, 180, 220 grit
[ ] Waterborne polyurethane (preferred for bathroom) OR oil + poly blend
[ ] Tack cloth or microfiber rags
[ ] Optional: wood conditioner + light stain if matching other bathroom wood

TOOLS
-----
[ ] Stud finder
[ ] 24 in (or longer) level
[ ] Tape measure + pencil
[ ] Painter’s tape
[ ] Drill / driver + bits matching bracket rod diameter
[ ] Circular saw or table saw; miter saw for square ends
[ ] Clamps (if laminating)
[ ] Optional: 1/8 in roundover bit or sanding block for edge break

CONSUMABLES
-----------
[ ] Painter’s tape (wall layout marks)
[ ] Masking paper / drop cloth for finishing
