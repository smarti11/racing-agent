FINISH SCHEDULE — Bathroom Poplar
=================================
Goal: sealed, smooth shelves that tolerate humidity. Prefer waterborne polyurethane.

1. Sanding sequence
-------------------
[ ] 120 grit — remove mill marks, glue squeeze-out, high spots
[ ] 180 grit — refine; ease edges consistently on both shelves
[ ] 220 grit — final pass on all faces and ends
[ ] Vacuum + tack cloth — no dust before finish

2. Optional stain
-----------------
Poplar can take stain blotchily. If staining:
[ ] Apply wood conditioner per product directions
[ ] Wipe stain evenly; match both shelves in the same session
[ ] Dry fully before topcoat

If keeping natural poplar: skip stain; go straight to clear topcoat.

3. Topcoat (waterborne polyurethane — recommended)
--------------------------------------------------
[ ] Thin first coat if product allows (or use as directed)
[ ] Brush or wipe with the grain; coat all six faces (including back)
[ ] Dry per label
[ ] Light 220 scuff between coats; remove dust
[ ] Apply 2nd coat
[ ] Apply 3rd coat on top face and front edge (highest wear / moisture exposure)
[ ] Cure fully before install — prefer 24–48 h beyond dry-to-touch for bathroom use

4. Oil + poly alternative
-------------------------
[ ] Wipe-on oil for color/depth
[ ] Then 2–3 coats wipe-on poly, same scuff/dust discipline as above

5. Pre-install inspection
-------------------------
[ ] Both shelves same sheen and color
[ ] No sticky spots
[ ] Bracket holes still clear (mask holes with tape before finishing, or re-clear carefully)
[ ] Finished thickness still ~1.50 in (confirm bracket fit)
